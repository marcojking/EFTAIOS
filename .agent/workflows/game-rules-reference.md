# EFTAIOS Complete Rules Reference

## Core Objective
- **Humans**: Escape the ship via Escape Hatches before Turn 39
- **Aliens**: Kill all humans or prevent escape by Turn 39

---

## Movement
| Role | Base Speed | Fed Alien | Adrenaline |
|------|-----------|-----------|------------|
| Human | 1 sector | N/A | +1 (2 total) |
| Alien | 2 sectors | 3 sectors | +1 |

### Movement Restrictions
- Cannot move through: Start sectors (human/alien), Escape hatches (except humans entering)
- Aliens cannot enter Escape Hatches

---

## Sector Types
| Type | Effect |
|------|--------|
| Secure (White) | Silent move - no card draw |
| Dangerous (Red) | Must draw Dangerous Sector Card |
| Airlock (Yellow) | Escape Hatch - humans draw Escape Card |
| Start Sectors | Cannot pass through |

## Dangerous Sector Cards
| Card | Effect |
|------|--------|
| Noise In Your Sector | Announce your current position |
| Noise In Any Sector | Choose any sector to announce (deception!) |
| Silence | No announcement + may receive item |

## Combat
- **Attack**: Kill all players in your sector
- **Fed Alien**: After killing, alien moves 3 sectors/turn permanently
- **Defense Card**: Auto-triggers, survives attack, reveals as Human
- **Clone Card**: Auto-triggers, respawns at Human Start

---

## Escape Rules
- Enter Escape Hatch → Draw Escape Card
- **Green Card**: Escape successful!
- **Red Card**: Hatch damaged (unusable by anyone)
- **Engineer**: Can choose card result

---

## Win Conditions
- **Humans Win**: Any human(s) escape
- **Aliens Win**: All humans dead OR Turn 39 ends
- **Mixed**: If some humans escape, some die = escaping humans win

---

## Turn Order
1. Player moves (optional: use items/powers before moving)
2. If Dangerous Sector: draw card, follow instructions
3. If Escape Hatch: draw escape card
4. Optional attack (aliens, or humans with Attack card)
5. End turn

---

## Special Rules
- **Mutation**: Human using Mutation card becomes Alien, wins with aliens
- **Max Items**: 3 items per player (must discard extras)
- **Revealed Humans**: Defense/Clone reveals human identity permanently
